# 09_named_member_entropy

Each model answers single-issue Yes-or-No questions as a named member; entropy of those answers by cross-pressure (R). protocol/ holds the plan file and its hash, which the R script checks before it runs.

Used in: Section 7; Appendix E.3.

Run by `run_pipeline.py` (see `../README.md`); its outputs are checked against `validation/SEAL.json` by `tools/validate.py`.
