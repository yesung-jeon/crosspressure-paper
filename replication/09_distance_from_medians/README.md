# 09_distance_from_medians

Placement of aligned and cross-pressured member-Congresses by distance from the medians of the two roll-call scales (terciles and a 0.5 SD cut), with member-resampled intervals. Protocol in `protocol/`.

Used in: Section 5; Appendix C.7.

Pipeline steps (1): `validity.v2`.

Run everything through `python run_pipeline.py` from `replication/`; outputs go to `out/` (or `analysis/results*` for the R analyses).
