# 01_rollcall_scales

Builds the economic and abortion roll-call scales from Voteview votes, one per Congress and chamber (first principal component, oriented so that higher is more conservative), and the quadrants of each member-Congress.

Used in: Section 3; Appendix A.2-A.3.

Run by `run_pipeline.py` (see `../README.md`); its outputs are checked against `validation/SEAL.json` by `tools/validate.py`.
