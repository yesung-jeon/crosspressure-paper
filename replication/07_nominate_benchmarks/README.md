# 07_nominate_benchmarks

Nokken-Poole comparison of continuing members and replacement; the NOMINATE fit (geometric mean probability) of cross-pressured members and the vote-accuracy gap holding that fit constant.

Used in: Section 4; Appendix B.3, D.8.

Pipeline steps (3): `nominate.n1`, `nominate.n1_synthetic`, `nominate.n2`.

Run everything through `python run_pipeline.py` from `replication/`; outputs go to `out/` (or `analysis/results*` for the R analyses).
