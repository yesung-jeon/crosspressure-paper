# 02_ideology_map

Extracts the economic and social directions from each model, chooses the layer (steering judged by a model), places every member-Congress on the map, compares the map with the roll-call quadrants, places the 60 members selected by their votes, and runs the stated-profile task. out_layercheck/ repeats the extraction and layer choice from the start.

Used in: Sections 3-5; Appendix A.4-A.5, C.1-C.6.

Run by `run_pipeline.py` (see `../README.md`); its outputs are checked against `validation/SEAL.json` by `tools/validate.py`.
